## Учебные работы по машинному обучению

РосНоу, дисциплина «Методы машинного обучения», кафедра Интеллектуальных
информационных систем и кибербезопасности. Три практики, 8 ноутбуков:

- **Классические алгоритмы** - линейная и логистическая регрессия, дерево
  решений, случайный лес. Свой датасет на каждую модель
- **Базовые нейросети** - полносвязная (MLP) на табличных данных, свёрточная
  (CNN) на MNIST, рекуррентная (LSTM) на временном ряде
- **Глубокое обучение** - дообучение DistilBERT под тональность отзывов в трёх
  режимах, чтобы измерить, что именно даёт предобучение

Сквозная методика во всех работах: три выборки, подбор гиперпараметров по
валидации, а не по тесту, сравнение с базовой линией, зафиксированные seed и
раздел ограничений. Учебные репозитории приватные, высылаю доступ по запросу.
